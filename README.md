WORKSPACES

Your productivity. Your space. Everything in one place.

Workspaces is a modern, responsive productivity web application designed to bring essential everyday tools together in one organized and customizable environment.

Whether you're managing tasks, writing notes, tracking time, or organizing useful links, Workspaces gives you the tools to stay focused and productive.

FEATURES

Notes
Create, edit, delete, and automatically save your notes.

Todo Manager
Organize and track your daily tasks.

Calculator
Perform everyday calculations.

Calendar
View dates and organize your schedule.

Stopwatch
Track time with a built-in stopwatch.

Quick Links
Save and organize frequently visited websites.

Clock and Date
Keep track of the current time and date.

Daily Quotes
Get a little inspiration throughout your day.

Dark and Light Mode
Switch between themes for a comfortable experience.

Progressive Web App
Install Workspaces on supported devices and access supported features offline.

BUILT WITH

HTML5
CSS3
JavaScript
Font Awesome
Progressive Web App technologies
Local Storage

RESPONSIVE DESIGN

Workspaces is designed to provide a consistent experience across desktop, tablet, and mobile devices.

GETTING STARTED

Clone the repository:

git clone https://github.com/crotekh-dev/Workspaces.git

Navigate into the project folder:

cd Workspaces

Open the project using VS Code.

Run the application using Live Server or another local development server.

Workspaces was created to make everyday productivity simpler by bringing multiple useful tools into one accessible workspace.
